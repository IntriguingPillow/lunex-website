Put the official cloud partner logos in this folder using exactly these names:

  aws.svg
  google-cloud.svg
  alibaba-cloud.svg
  tencent-cloud.svg
  huawei-cloud.svg
  byteplus.svg

- SVG is best (sharp at any size). PNG also works: rename the file to .png AND
  change the matching src="assets/img/clouds/....svg" in services.html.
- Use the full-colour version made for light/white backgrounds.
- Get them from each provider's partner portal or brand guidelines.
- If a file is missing, the Services page shows the coloured planet instead.
